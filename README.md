## ✨ Features

- 🚌 **Multi-Modal Fare Comparison**: Real-time realistic pricing across **Bus**, **Train**, **Flight**, **Cab / Taxi**, and **Auto / Bike Bud**.
- 🔍 **Live Search Engine & Geocoding**: Powered by OpenStreetMap Nominatim and live Wikipedia integration for instant destination summaries and photos.
- ⛅ **Live Weather Integration**: Real-time temperature and weather conditions at any searched destination via Open-Meteo.
- 🗺️ **Interactive Route Mapping**: Interactive Leaflet maps with route visualizers, distance calculators, and waypoint markers.
- 📸 **High-Resolution Photography**: Handpicked, high-definition photography across Kerala (Munnar, Alleppey, Fort Kochi, Varkala, Wayanad) and global dream destinations.
- 📱 **PC & Mobile Responsive**: Pixel-perfect responsive design tailored for desktops, widescreen monitors, tablets, and smartphones.
- 🎫 **Digital Ticket Records**: Interactive digital tickets with one-click print and PDF export capability.
- ♿ **Senior & Accessibility Mode**: Built-in speech synthesis (read aloud) with clean high-contrast controls.
- 🔒 **Offline-Ready Resilience**: Bundled data fallbacks guarantee smooth performance even under weak cellular reception.

## 🛠️ Tech Stack

- **Frontend**: React 18, Tailwind CSS, Lucide Icons
- **Mapping & GIS**: Leaflet.js, OpenStreetMap
- **Data & APIs**: Wikipedia REST API, Open-Meteo Weather API
- **Design System**: Plus Jakarta Sans, Inter, Glassmorphism, Dark/Light mode adaptive

## 📦 Local Setup

To run locally, simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/Haxionbuilders/travbud.git
cd travbud
# Open index.html in your browser
```
